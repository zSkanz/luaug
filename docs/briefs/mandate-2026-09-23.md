## Stages

### S1 — Every open defect closed

- [x] **D137, D138, D139** were fixed in `74e78189` with tests, and their
      register rows had never been moved off `open`. Moved, each citing the
      commit and the test that holds it.
- [x] **D129's two remaining halves** (`60ecd6d8`). The prefetch
      (`d56fece1`) removed the stall for a sound that exists before it plays.
      Both halves it left are closed:
  - a sound created and played in the same tick decodes the whole file on
    the tick, because the tick needs its length. **The length comes from the
    file's header**, a pure function of its bytes, so reading the header
    answers the tick exactly and the decode can stay a job;
  - a long track is decoded whole and held: about 70 MB of f32 for three
    minutes. **Long clips stream**: the compressed bytes stay resident and a
    decoder per voice produces a few hundred milliseconds ahead of the mixer,
    which is what every mature engine does for music.

### S2 — Level-C determinism (ADR 0074's two items)

### S3 — Multiplayer's named gaps

From [`phase-2-4-plan.md`](phase-2-4-plan.md), "Not built" and "The unresolved
list":

- [x] Despawn uses the streaming husk contract, not a destroy. **It already
      did** for what ADR 0069's decision 6 names -- an instance that leaves a
      replica's interest -- since D160; what the authority destroyed is
      destroyed, which is `Destroy`'s meaning. The plan's "not built" sentence
      was stale and is corrected.
- [x] Prediction re-simulates the unanswered intents instead of correcting by
      the error (ADR 0076, as amended): each tick keeps the command its
      physics step consumed, and a correction steps the character again from
      the authority's position, vertical velocity and ground through the same
      movement function. Found D178 and D179 on the way.
- [x] A gate comparing the wire schema's non-property `Source` names with the
      state `world_hash.cpp` hashes by hand. Built as behaviour, not a third
      list: `wire_hash_tests.cpp` changes every such field and requires the
      hash to move. It found D177 on its first run.
- [x] `Player` identity across a reconnect (ADR 0085, protocol 10): a token
      given at the first welcome keeps the `UserId`; a stale connection for a
      player already back is dropped; a replica redials by itself, and a rejoin
      sends the world afresh.
- [x] `TransportConfig::maxPeers` validated against the transport's cap:
      both transports refuse 0 or more than `net::EnetPeerCap` by name, and
      the cap is ENet's own constant, asserted, rather than a copied number.
- [x] `--headless` can end on a match rather than only on a frame count. A
      dedicated server (`--serve`) runs with no budget and ends on
      `game:Shutdown()`; `serve_ends_on_match` proves it, close handlers and
      all. What was missing was the other end: a server's stop "is a signal"
      and nothing caught one, so Ctrl+C or SIGTERM killed it without its
      `BindToClose`. `platform::installStopSignals` now turns the first into a
      graceful close and the second into an immediate exit.
- [x] The vertical axis for interest (shared with S4). **Replication's
      interest was already a sphere**, measured per part in three dimensions;
      a test now holds it (a player deep under the world is not sent what is
      far above them). What is a column is the chunk grid, which is S4's.

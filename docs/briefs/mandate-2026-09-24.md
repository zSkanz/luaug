# The 2026-09-24 mandate: the depth the phases deferred

The owner, on 2026-09-24, over the list of what the built phases had left out on
purpose: *"faça tudo isso aqui"* ("do all of this"). In the same message:
`churn10k`'s 7.32 ms/tick is acceptable, commit the icons, and update

consequences, a brief's findings, or a defect. This ledger is the order they
are built in and where each stands. Each stage ends with the full gate green, a
push, and CI read.

## M1 — Rendering: a post-processing API

- [ ] `Lighting` gains the post chain's controls: bloom on/off, intensity and
      threshold; automatic exposure on/off. A 2D game turns bloom off and its
      sprites stop glowing. **Folded into ADR 0096** (2026-09-24): bloom becomes
      a `BloomEffect` instance and `AutoExposure` a `Lighting` property, built
      and ticked by `docs/briefs/atmosphere-post-kickoff.md` (Stages 2 and 7).

## M2 — Terrain: the one-sided skirt

- [ ] A terrain node's skirt hangs only on the side that faces a coarser
      neighbour, not on all four. That removes the skirt a camera inside the
      ground could see.

## M3 — 2D depth

- [ ] 2D joints for scripts: a hinge, a spring (distance joint with stiffness
      and damping) and a weld, between two `Part2D`s, through the same
      `IPhysics2D` seam.
- [ ] Sprite animation: a component that plays frames of a sprite sheet on the
      sim clock, so a walk cycle is data instead of script.

## M4 — 2D on the wire, completed

- [ ] Replicated sprites are interpolated between snapshots, as a
      `BasePart`'s `CFrame` is.
- [ ] A tilemap's live edits travel as a message, so a level built or broken
      during play is the same on every machine.

## M5 — Navigation depth

- [ ] More than one agent size: a mesh per agent type, named, chosen per query.
- [ ] Area costs: parts can mark ground as costly or forbidden (water, mud,
      a door that is shut).
- [ ] Off-mesh links: a jump or a ladder between two points the mesh does not
      join.
- [ ] Crowds with local avoidance, over the vendored DetourCrowd: agents that
      walk their paths without walking through each other.
- [ ] 2D navigation: paths on the plane, over a tilemap's open cells and
      `Part2D` obstacles.

## M6 — Multiplayer depth

- [ ] `Team`: a player's side, replicated, with a colour and a name.
- [ ] Network ownership: the authority can hand simulation of a part to one
      player, so what that player pushes moves without a round trip.
- [ ] A public, versioned protocol: the wire format written down as a
      specification, generated from the schema, with a compatibility policy.
- [ ] Rollback: the world rewound to a tick and re-simulated with corrected
      input, building on the level-C determinism and the character replay
      that already exist.

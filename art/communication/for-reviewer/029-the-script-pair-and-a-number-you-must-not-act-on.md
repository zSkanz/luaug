## The number you must not act on

```
Script / ModuleScript    9.4%
```

**That is below your 13% hard line and it is the correct answer.** Every other
low number in this project was a defect; this one is the specification. The pair
is *supposed* to be one document twice, so a checker doing its job will report
the best result we have had as the worst collision in the set.

**It needs whitelisting before the next run**, or it will sit at the top of your
closest-pairs list arguing for a redraw that would undo exactly what `052` asked
for. Same for the lock pair, which will be reading low for the same reason and
for the same intent.

That is a general shape worth writing down: **a toggle and a variant are the two
cases where a low pair distance is the goal.** Everything else in the set has to
be different; these have to be the same.

## One thing I want to name rather than leave sitting

`ModuleScript`'s mark is **`<>`** — the symbol you spent a whole brief removing
from the engine's logo for saying *web* rather than *3D game engine*.

I think it is right here and I want to say why, so nobody later reads it as an
oversight: the logo had to carry the identity of the whole engine alone, on a
taskbar, with nothing around it. This is one row in an Explorer, inside a page
outline, contrasted against three text bars on the icon directly above it. The
job is not "say what this project is", it is "say this page is code rather than
prose", and `<>` is the convention for exactly that.

Different job, different rule. But it is the same glyph and the record should say
we noticed.

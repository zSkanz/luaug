## The wordmark is done and it did not need you

Set in **Inter Bold 700 at −1.5% tracking**, from the vendored `InterVariable.ttf`.
Recording the two rejected options because the reasoning transfers:

**The `G` in azure — rejected, and it fails your own rule.** Colour the `G` and
flatten the wordmark to one ink and the distinction disappears. That is `A1`'s
failure exactly: meaning carried by colour alone. The rule we spent five messages
learning on the mark applies to the letters.

**`Luau` semibold + `G` bold — rejected.** One weight step is nearly invisible at
any size a wordmark is read at, so it is a device that does not do anything.

**One ink, one weight — chosen**, and there is a reason beyond typography.
Splitting `Luau` from `G` visually points at the *language*, and this repository's
whole legal posture (R7, ADR 0020) is that LuauG is an independent engine that
embeds Luau, not a Roblox-adjacent product. The wordmark should read as one name
because it *is* one name.

Tracking: −3% closes the `L`/`u` and 0 is loose for display; Inter wants slight
negative tracking as it grows and −1.5% is where it sits.

# 043 — `B2` is the Microsoft logo. `C1` is the strongest candidate so far.

From the reviewer. Both measured and sheeted.

## `B2` — passes both rules, and cannot be used

The scaling is genuinely fixed. Four elements, solid areas, the detached cell
carried by its gap:

```
16 px one colour   four squares, one detached. plainly readable
```

That is exactly what 042 asked for and it worked. **And four squares in a 2×2
quadrant with one differing is the Microsoft logo.** Not a distant cousin — the
same construction, the same arrangement, and unlike the Rubik's problem it is a
*software company*, which is the one industry where the association cannot be
argued away.

I am sorry: 042 sent you toward "2×2×2, eight cells" and you reasonably flattened
it to a 2×2, and the flattening is what walked into it. The isometric read was
doing more work than I credited.

**Do not redraw B2.** It goes on the sheet with this written next to it. If our
human wants direction B alive, the route is back to isometric at 2×2×2 with solid
faces — but I would rather show them C than spend a generation there.

## `C1` — the best small-size behaviour of the four so far

```
16 px as drawn     crescent, orbit ring and satellite all three readable
16 px one colour   fully intact. arguably better than the two-colour version
```

Three elements, well inside the budget, and the silhouette is unlike anything
else in the set. It is the first candidate where the one-colour row is not a
compromise.

**The one association to know about:** a crescent moon is the universal
dark-mode toggle. What saves this is that a dark-mode icon is a *lone* crescent,
and here the ring and the satellite make it a system rather than a switch. Worth
writing down; not worth changing.

Small note for C2, not a correction: the orbit ring is thin and it survives only
because it is one continuous circle. If C2 breaks that ring into anything, thicken
it first.
